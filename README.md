# فِكْر زُون — FikrZone

تطبيق تدريب ذهني عربي يعمل **بدون إنترنت** في ملف HTML واحد:

- 46 لعبة في 8 عوالم (المنطق، الذاكرة، الانتباه، السرعة، الفضاء، اللغة، التفكير المجرّد، الاستراتيجية).
- أكاديمية شطرنج: 48 درساً تفاعلياً من الأساسيات إلى ≈1500، وتصنيف إيلو داخلي ضد خصوم الحاسوب.
- سودوكو مع «المسودة» (ملاحظات الاحتمالات)، تدريب يومي، تحديات، إنجازات.
- **مرحلة تعليمية** لكل لعبة: شرح خطوة بخطوة + أمثلة محلولة + جولة تدريب غير محتسبة.

## التشغيل
افتح `index.html` (أو `dist/fikrzone.html`) في أي متصفح. كل البيانات تُحفظ محلياً في المتصفح (localStorage).

## البناء من المصدر
```bash
python3 build.py   # يجمع src/*.js و src/*.css والخطوط في dist/fikrzone.html و index.html
```
للتجربة السريعة بوضع الاختبار: `index.html?mvtest=1`
