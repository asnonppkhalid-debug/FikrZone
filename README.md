# فِكْر زُون — FikrZone

تطبيق تدريب ذهني عربي يعمل **بدون إنترنت** في ملف HTML واحد:

- 46 لعبة في 8 عوالم (المنطق، الذاكرة، الانتباه، السرعة، الفضاء، اللغة، التفكير المجرّد، الاستراتيجية).
- أكاديمية شطرنج: 48 درساً تفاعلياً من الأساسيات إلى ≈1500، وتصنيف إيلو داخلي ضد خصوم الحاسوب.
- سودوكو مع «المسودة» (ملاحظات الاحتمالات)، تدريب يومي، تحديات، إنجازات.
- **مرحلة تعليمية** لكل لعبة: شرح خطوة بخطوة + أمثلة محلولة + جولة تدريب غير محتسبة.

## التثبيت كتطبيق (PWA)
عند نشر المشروع على رابط https (مثل GitHub Pages) يصبح قابلاً للتثبيت: أيقونة على الشاشة الرئيسية، شاشة كاملة، ويعمل بدون إنترنت بعد الزيارة الأولى.
- Chrome/Edge/Android: زر «تثبيت» داخل التطبيق (الإعدادات أو الرئيسية) أو من قائمة المتصفح.
- iPhone/iPad: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- التحديثات: تُحمَّل تلقائياً عند الاتصال بالإنترنت (الـ Service Worker يتغيّر إصداره مع كل بناء).

## التشغيل
افتح `index.html` (أو `dist/fikrzone.html`) في أي متصفح. كل البيانات تُحفظ محلياً في المتصفح (localStorage).

## البناء من المصدر
```bash
(cd fonts && npm install)   # مرة واحدة: خطوط Plex وReem Kufi
python3 build.py   # يولّد: dist/fikrzone.html (ملف واحد) + index.html + sw.js (نسخة الويب القابلة للتثبيت)
```
للتجربة السريعة بوضع الاختبار: `index.html?mvtest=1`
